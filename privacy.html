Privacy policy

Last updated: 3 November 2026

This policy describes Our Place (Family Dashboard), a personal household application maintained by Kevin Rijnders. The operational dashboard runs on the household’s own server. These public information pages are hosted separately on GitHub Pages.

Private calendar feed

The household operator provides Google Calendar’s Secret address in iCal format. This address grants read-only access to the events in that calendar and is treated as a credential. The dashboard retrieves event titles, dates, times, descriptions, locations and recurrence information to display the household calendar. It does not sign in to Google, request OAuth permissions, or create, change or delete events. Events are managed directly in Google Calendar.

Where information is stored

The secret feed address is stored in an owner-readable and owner-writable file on the household server. It is not returned to dashboard browsers or published to this website. Treat the address as a password; anyone who obtains it may be able to read the feed. Calendar events are cached in server memory for five minutes, and a previously downloaded copy may remain in memory during temporary download failures. Household browsers receive event details for display.

Other dashboard settings, lists and photos remain stored on the household server. Protected backups may include the feed address. Unused encrypted Google OAuth credentials may remain from older versions; the iCal dashboard does not read or use them.

Household access and sharing

Devices permitted to access the private dashboard can see the configured calendar and use the available home and household actions. The dashboard currently uses trusted home-network access rather than individual household sign-ins, so the operator should only allow trusted people and devices onto that network.

Google user data is not sold, supplied to advertising networks, used for advertising, or used to train artificial intelligence models. It is not published on this information website or sent to GitHub Pages. Google receives Calendar API requests needed for the integration. No external analytics or advertising service is embedded in these information pages.

Other dashboard features

Family member details, chores, shopping lists, uploaded photos and configuration are stored on the household server as needed for those features. Some display preferences are saved in browser or Android WebView local storage. Home Assistant and Blink connections communicate with their respective systems; Blink live viewing still relies on Blink’s services. The dashboard’s weather service requests weather for the configured location without sending Google Calendar data.

Retention, disconnection and deletion

Use Settings → Calendar → Disconnect feed from localhost on the server laptop to remove the saved feed address and clear the server’s in-memory event cache. This does not delete Google Calendar events. To invalidate a previously shared or exposed secret address, reset it in Google Calendar’s Integrate calendar settings. Old browser views may retain displayed events until refreshed; protected backups must be removed separately.

For other local dashboard data or unused credentials from an older version, contact the household operator. Legacy Google authorisations can also be revoked through the Google Account’s third-party connections settings.

Public website hosting

GitHub Pages serves these public pages and may process visitor IP addresses and request information for hosting and security purposes under the GitHub privacy statement. These pages do not connect visitors to the private dashboard and do not contain embedded live household data.

Google API user data commitments

Our Place’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact and updates

For account access or data deletion, contact the household operator, Kevin Rijnders. The maintainer’s public profile is github.com/KevinRijnders. Household users may contact the operator directly; do not post private calendar information, passwords or tokens in public GitHub discussions. This policy will be updated when the dashboard’s data practices change.
