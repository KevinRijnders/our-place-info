Privacy policy

Last updated: 3 November 2026

This policy describes Our Place (Family Dashboard), a personal household application maintained by Kevin Rijnders. The operational dashboard runs on the household’s own server. These public information pages are hosted separately on GitHub Pages.

Google Calendar data and permissions

When an account owner connects Google Calendar, the dashboard requests access to read the account’s calendar list and to view and edit calendar events. It uses calendar identifiers, names, colours and access permissions to let the user select calendars. For selected calendars, it accesses event titles, dates, times, descriptions, locations, recurrence information and identifiers needed to display or manage events.

It uses this information to show the household calendar and to create, update or delete events when an authorised household user requests it. Changes are sent to Google. Google may send notifications to existing event guests as part of those changes. The dashboard does not request Gmail or Google Photos access.

Where information is stored

Google remains the source of truth for Calendar events. The dashboard backend retrieves event information and sends it to authorised household devices for display; it does not maintain a separate event database for Google events. Calendar selection and other dashboard data are stored on the household server. Devices may temporarily hold displayed information in memory.

Google OAuth tokens are stored encrypted on the household server. The encryption key is stored separately on that same server, with restricted file permissions. The OAuth client secret stays on the backend. These protections do not protect against someone who gains access to both the stored tokens and their encryption key. Protected backups may contain copies of these files.

Household access and sharing

Devices permitted to access the private dashboard can see its selected calendars and use the actions available to them. The dashboard currently uses trusted home-network access rather than individual household sign-ins, so the operator should only allow trusted people and devices onto that network.

Google user data is not sold, supplied to advertising networks, used for advertising, or used to train artificial intelligence models. It is not published on this information website or sent to GitHub Pages. Google receives Calendar API requests needed for the integration. No external analytics or advertising service is embedded in these information pages.

Other dashboard features

Family member details, chores, shopping lists, uploaded photos and configuration are stored on the household server as needed for those features. Some display preferences are saved in browser or Android WebView local storage. Home Assistant and Blink connections communicate with their respective systems; Blink live viewing still relies on Blink’s services. The dashboard’s weather service requests weather for the configured location without sending Google Calendar data.

Retention, disconnection and deletion

The dashboard retains its Google authorisation until the user disconnects, revokes it, or Google invalidates it. Use Settings → Google Calendar → Disconnect from localhost on the server laptop to remove the dashboard’s saved OAuth token file and selected calendars. The app also attempts to revoke its Google grant. You can independently revoke the app’s access through your Google Account’s third-party connections settings. Disconnecting does not delete events from Google Calendar.

To remove other local dashboard data, contact the household operator to delete the relevant records, uploaded files or local storage. Previously made backups must be removed separately. Normal event creation, editing and deletion remain available through Google Calendar and the authorised dashboard.

Public website hosting

GitHub Pages serves these public pages and may process visitor IP addresses and request information for hosting and security purposes under the GitHub privacy statement. These pages do not connect visitors to the private dashboard and do not contain embedded live household data.

Google API user data commitments

Our Place’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact and updates

For account access or data deletion, contact the household operator, Kevin Rijnders. The maintainer’s public profile is github.com/KevinRijnders. Household users may contact the operator directly; do not post private calendar information, passwords or tokens in public GitHub discussions. This policy will be updated when the dashboard’s data practices change.
